# Läut Premium Beer – Site institucional

Landing page da **Läut Premium Beer**, serviço de chopp premium para festas e eventos em Viçosa – MG.

🔗 **Site no ar:** https://raphasouza28.github.io/laut-beer/

## Sobre o projeto

Site de página única desenvolvido pela [Enlace Services](https://github.com/RaphaSouza28) para apresentar o serviço e converter visitantes em pedidos pelo WhatsApp.

## Seções

- **Início** – apresentação da marca
- **Como funciona** – passo a passo do serviço
- **Planos e preços** – opções de pacotes
- **Tudo incluso** – itens que acompanham cada plano
- **Calculadora** – ajuda o cliente a descobrir o pedido ideal para a festa
- **Cervejas e outras bebidas** – catálogo de produtos
- **Galeria de festas**

## Tecnologias

- HTML5 e CSS3
- Bootstrap 5
- JavaScript
- Google Fonts (Playfair Display, Cormorant Garamond, Montserrat)
- Hospedagem no GitHub Pages

## Como rodar localmente

Basta abrir o arquivo `index.html` no navegador — não há etapa de build.
